# ADB 维护密钥

`adbkey` 是客户端私钥，`adbkey.pub` 是对应公钥。用于访问设备远程 ADB，不参与 OPi4 交付包。

设备使用 `ro.adb.secure=1` 和 `/data/misc/adb/adb_keys` 白名单。新增工作站可将其公钥追加到白名单；恢复既有客户端身份时，将这对文件安装到该工作站的 `.android` 目录，并限制私钥读取权限。保留工作站原有密钥副本，避免覆盖后失去其他设备授权。

更新客户端密钥后重启对应端口的 ADB server，使其重新加载密钥。未授权连接应按白名单处理，不关闭 ADB 认证。私钥离线备份，不进入公开仓库。
