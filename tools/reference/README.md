# 参考材料

| 目录 | 内容 |
|---|---|
| kernel | USB gadget / DWC3 源码摘录和角色切换补丁 |
| hwc | Rockchip HWC 实现，用于核对物理显示属性 |
| edid | EDID 生成器与测试数据 |

HWC 来源为 `khadas/android_hardware_rockchip_hwcomposer`，记录提交 `fd70146`、版本 0.54；第三方来源和许可证保留在各目录中。

当前运行脚本在 `deploy/opi4/scripts/`。这些参考实现不直接进入交付包，固件构建与恢复见[恢复说明](../../docs/flash-boot-and-adb-recovery.md)。
