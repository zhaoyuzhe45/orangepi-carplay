# NCM NDP16 布局参考

供 `src/ncm_bridge.c` 和 NTB 诊断使用。NDP16 每个表项为 4 字节：前两字节是小端 `wDatagramIndex`，后两字节是小端 `wDatagramLength`；以 `{0,0}` 结束，不能按 NDP32 的索引宽度解析。

当前单帧布局为 NTH16 头 12 字节、NDP16 头 8 字节；首项 index 在偏移 20、length 在 22，终止项在 24/26，数据从偏移 28 开始。多帧布局按表项数量计算数据偏移。

验收同时检查生成端和解析端的边界、对齐、终止项、数据长度和真实收包。TUN 有数据而对端无包时，还需排查 USB 写入是否阻塞及配置切换后的端点生命周期。
