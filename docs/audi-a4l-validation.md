# 实车验收

显示、旋钮、上一首/下一首、仪表歌名和媒体音乐已获用户确认。后续更新按以下项目复测，记录车型、交付哈希、连接方式、启动时间和 boot ID。

| 项目 | 检查内容 |
|---|---|
| 冷启动 / 重连 | 插入到首个真实画面的耗时；自动重连是否成功，是否重复停在车标 |
| 显示 | 完整画面、比例、触控位置；非预设尺寸能否正确编码；下次启动是否使用成功缓存 |
| 输入 | 旋钮快慢转、确认/返回、上一首/下一首方向与响应 |
| 音乐 / 导航 | 媒体音量可调、歌名正确、导航播报与压低音乐、播报结束恢复 |
| 麦克风 / 电话 | 分别检查车机麦克风开关；语音搜索、常驻唤醒、真实通话、回声及通话后恢复 |
| GPS | 高德/百度位置和桌面速度连续变化；断连后不继续发布旧位置 |
| 网络 | 默认蓝牙备用关闭；手动启用时检查 Wi-Fi 优先、断网切换及 Wi-Fi 恢复 |

GPS 仍需连续行驶至少 30 分钟复测，重点覆盖连接十几分钟后曾出现约十分钟数据延迟的场景。用[现场采集](validate-usb-on-host.md)同时记录 NMEA 内容时间、接收序列/年龄和 Android 回调；位置短时更新或到达年龄小不能作为长时问题通过的依据。

真实通话、导航语音、共享麦克风音质及全部分辨率组合的实车覆盖仍有限。本机和台架测试用于回归，不能代替以上体验检查。
